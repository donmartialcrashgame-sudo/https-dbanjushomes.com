HOW TO USE THIS PAGE

What happens while DBH completes sign in

This page is a secure transition page used after an authentication provider or account recovery flow returns to DBH. Normally you do not need to enter anything here.

01 — Wait for verification

DBH receives the authentication response and checks the session information.

02 — Session is stored

When the response is valid, the authenticated session is prepared for the DBH application.

03 — Continue to your account

You are redirected to the authenticated dashboard after successful sign in.

If this page stays here

Wait briefly, then try signing in again. If the problem continues, return to the login page or contact DBH support. Never send authentication tokens or recovery links to another person.
