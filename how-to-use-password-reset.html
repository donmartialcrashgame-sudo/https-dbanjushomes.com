How to Use the DBH Password Reset Page

Understand what the DBH password reset page does, how to use it safely and what to do if a reset link expires.

Step-by-step guide

Use the instructions below to understand this DBH page and complete the relevant task safely.

01

Only use a valid reset link

Open the reset page through the secure recovery flow sent to your account email.

02

Enter your new password

Create a password of at least eight characters. Avoid names, simple sequences and passwords used on other sites.

03

Confirm the new password

The confirmation value must exactly match the new password.

04

Submit once

Select Update password once and wait for the result. Do not repeatedly submit the form.

05

Return to Sign In

After a successful change, use the new password from the normal DBH Sign In page.

06

If the link is expired

Return to Forgot password and request a new recovery message rather than trying to reuse an invalid link.

07

Protect the new credential

Do not send the new password to DBH staff, friends, agents or anyone else.

08

Report suspicious activity

If you believe another person accessed your account, change the password and contact DBH using its published contact channel.
